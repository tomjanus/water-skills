# Tutorial index

Welcome to the water-skills ramp-on curriculum. These eight lessons take you from "what is this repository?" to "I can use, propose, or author a skill."

## Two tracks, one lesson set

Each lesson is a single Markdown file with two paths:

- **Plain-language path** — no terminal, no git, no agent. For managers and water engineers.
- **Operational path** — paths, commands, expected output, stop conditions. For engineers and agents.

Choose a track by navigation, not by content fork:

| Track | Lessons | Duration | Outcome |
|---|---|---|---|
| **Track A** — no git, no agent | 01, 02, 03, 04 | ~25 min | Install a skill for someone else; submit a proposal through the issue form |
| **Track B** — engineering and agent | 01, 02, 03, 05, 06, 07, 08 | ~50 min | Scaffold, validate, open a PR against `dev`, read an eval report, review a contribution |

## Lessons

1. **[What this repository is](./01-what-this-repo-is/)** — collection vs platform, the five loops, authoring-first order
2. **[Use a skill](./02-use-a-skill/)** — browse `skills/`, read `SKILL.md`, check inputs and limitations
3. **[Write knowledge, not documentation](./03-write-knowledge-not-docs/)** — knowledge-delta test, delete test, layered structure
4. **[Propose a skill without git](./04-propose-without-git/)** — issue form, triage, draft PR review (Track A only)
5. **[Propose a skill with git](./05-propose-with-git/)** — fork, branch, `SKILL.md`, validation, PR to `dev` (Track B only)
6. **[How we know a skill works](./06-how-we-know-skill-works/)** — task/trial/outcome vocabulary, pass@k/pass^k, GUI grading (Track B only)
7. **[Review and lifecycle](./07-review-and-lifecycle/)** — PR template, human and domain review, `review_status` (Track B only)
8. **[Work with agents in this repository](./08-work-with-agents/)** — disclose model/harness, agent templates, one canonical source (Track B only)

## Lesson rules

Every lesson follows these rules:

- Audience and outcome in the first line
- Plain-language path before operational path
- Duration ≤ 10 minutes
- Self-check questions with folded answers (`<details>`)
- Canonical links to `GLOSSARY.md`, `CONTRIBUTING.md`, `skills/`, `evals/` — no duplicated facts
- Exactly one "next link" at the end
- No quiz JavaScript; answers belong in collapsed `<details>` blocks
- Describes only what the repository does today — planned features are marked planned
