# water-skills

Agent skills for water science and engineering. Each skill transfers practical
engineering knowledge—assumptions, checks, software-specific procedures, failure
signatures, and limits—into concise instructions that an agent can apply with a
human engineer.

- [Browse the generated skill catalog](./catalog/)
- [Start the ramp-on tutorial](./tutorials/)
- [Read the installation and use guide](./guides/install/)
- [Contribute a skill](./guides/contribute-without-git/)

Skills are procedures, not endorsements that a model, simulation, or engineering
decision is correct. Format validation does not establish calibration, field
agreement, or scientific validity. Keep domain decisions with qualified people.
