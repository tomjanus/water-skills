# Bad skill

A skill is a reusable capability that gives an AI agent the procedural knowledge needed to perform specific tasks, including code generation, domain-specific work, and tool integration.

# What is a skill

Skills are reusable capabilities. They live in a directory and contain a SKILL.md file with metadata and instructions.

# Directory structure

skill-name/
├── SKILL.md
├── scripts/
└── references/

# Body

This skill is about doing the thing. First you do the thing, then you do the thing again, and finally you do the thing one more time to make sure the thing is done properly. There are many things to consider when doing the thing, and it is important to think about all of the things.
